Experiment 6b - Power BI (Popular Anime dataset)

1. Copy this whole folder to D:\DVT\Exp-6b\  (the data CSV must stay in the same folder).
2. Double-click the .pbip file - it opens in Power BI Desktop.
3. If you keep the folder somewhere else: Home > Transform data > Edit parameters > DataFolder
   and set the folder path (must end with a backslash), then click Refresh.
4. File > Save as > choose "Power BI file (*.pbix)" to get the .pbix for submission.
